# Data and Visualisation in BI
Code and files related to the course Data and Visualisation in BI.

This repository has files with commands and guides to help you get a quick overview of the material we have been through in the second part of the course. The files and their content are

1. [Basic Linux Commands.md](Basic%20Linux%20Commands.md): The Linux commands from the Introduction slides, one line each
2. [Basic Docker Commands.md](Basic%20Docker%20Commands.md): The Docker commands from the Docker I and Docker II slides, one line each
3. [Droplet and SSH setup guide.md](Droplet%20and%20SSH%20setup%20guide.md): Creating a droplet and connecting to it with SSH keys from Positron
4. [Working with a small droplet.md](Working%20with%20a%20small%20droplet.md): Adding swap to the droplet, and keeping only the Positron extensions needed for the course on the droplet, while keeping them in Positron on your laptop
